# functionalwelfare.com

The first-class web edition of the paper *"How's it going? Reinforcement learning in
language models recruits a functional welfare axis"* — designed so you can read the entire
paper (main text + appendices) on the web without opening the PDF.

The LaTeX source in `../valence-neurips/` is the **source of truth**. A converter turns it
into a structured JSON intermediate representation (IR); an Astro site renders that IR.

## Quick start

```bash
pnpm install
pnpm convert      # tex → IR + figure assets   (run whenever the .tex changes)
pnpm dev          # local site at http://localhost:4321
pnpm build        # static site → dist/
```

`pnpm convert` runs a one-time `latexmk -xelatex` prepass (cached) to get exact
figure/section/equation/citation numbers, then emits:

- `src/generated/manifest.json` — title, authors, abstract, epigraph, TOC, references,
  and a global `labelIndex` (label → unit + anchor).
- `src/generated/units/<slug>.json` — one IR document per section / appendix.
- `public/paper/fig/*.svg` — figures (PDF → SVG via `pdftocairo`).
- `public/paper/emoji/*.png` — the paper's emoji.

These generated artifacts are git-ignored and regenerated by `pnpm convert`.
Requires `latexmk`/`xelatex` and `pdftocairo` (poppler) on `PATH`.

## How it works

### Converter (`scripts/convert/`)
Built on [`unified-latex`](https://github.com/siefkenj/unified-latex).

| file | role |
|------|------|
| `parse.ts` | unified-latex parser + macro/environment signatures |
| `assemble.ts` | reads `neurips_2026.tex`; front matter + ordered units |
| `expand.ts` | splices `\input` files (TikZ inputs → asset macros) |
| `refs.ts` | latexmk prepass; parses `.aux`/`.bbl` → numbers + citations |
| `transform.ts` | AST → IR (macros, environments, math, footnotes, cross-refs) |
| `tabular.ts` | `tabular` → structured rows (colspan, rules, highlights) |
| `figures.ts` | PDF → SVG pipeline + emoji copy (cached) |
| `bib.ts` | `.bbl` → formatted, numbered references |
| `emit.ts` / `index.ts` | write JSON + orchestrate, with a summary report |
| `types.ts` | the IR node types (shared with the site) |

### Site (`src/`)
- `pages/index.astro` — main paper (Intro…Discussion + References), one page.
- `pages/appendix/[slug].astro` — one page per appendix.
- `components/paper/` — `Blocks`/`Inline` renderers + `Figure`, `Table`, `ModelExample`.
- `components/Toc.astro` — sticky sidebar table of contents.
- `lib/katex.ts` — build-time KaTeX with the paper's macro dictionary.
- `styles/global.css` — Cardo typography, constrained measure, margin sidenotes, theme.

### Swapping in "fancy" figures/tables
Every figure and table is keyed by its LaTeX label. To replace one with an interactive
HTML/JS version, drop a component in `src/components/overrides/figures/` (or `tables/`)
and register it:

```ts
// src/components/overrides/figures.ts
import EmotionScatter from "./figures/EmotionScatter.astro";
export const figureOverrides = { "fig:emotion_scatter": EmotionScatter };
```

Anything not registered falls back to the faithful static version — so you only build
interactive versions where they're worth it.
